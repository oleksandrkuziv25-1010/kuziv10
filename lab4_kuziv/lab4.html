Теоретичні відомості

1. Пошук елементів у DOM

Для роботи з елементами сторінки у JavaScript використовуються методи об'єкта document:

  • document.getElementById('id') — шукає унікальний елемент за ID.
  • document.querySelector('selector') — повертає перший елемент, що відповідає CSS-селектору.
  • document.querySelectorAll('selector') — повертає статичний список NodeList усіх відповідних елементів.
  • document.getElementsByClassName('class') — повертає динамічну HTML-колекцію елементів з відповідним класом.

2. Опрацювання елементів форм

Доступ до елементів форми здійснюється через колекцію document.forms або за допомогою атрибута name:

  • Радіокнопки (Radio): визначаються станом element.checked. В один момент активна лише одна кнопка з групи.
  • Прапорці (Checkbox): дозволяють множинний вибір, кожен чекбокс перевіряється окремо через checked.
  • Списки (Select): одиночний вибір зчитується через select.value, множинний — ітерацією по колекції select.options із перевіркою властивості option.selected.
  • Текстові поля: значення зчитується за допомогою властивості input.value.
